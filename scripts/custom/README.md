# 无人船推进模式切换脚本

## 功能说明

本脚本用于通过RC通道CH7切换无人船推进模式，具备以下功能：

1. **无人船模式切换**：通过CH7通道双重确认切换模式
2. **PWM输出控制**：禁用PWM1-4用于电机控制
3. **通道映射**：CH2/CH3映射到PWM5/PWM6控制推进器
4. **日志记录**：支持将运行日志写入SD卡
5. **安全机制**：开机稳定检测、非飞行状态限制

## 工作流程

### 切换到无人船模式
```
CH7: LOW → MIDDLE → LOW（保持500ms）
          ↓
   PWM1-4禁用（电机停止）
          ↓
   CH2映射到PWM6，CH3映射到PWM5
```

### 退出无人船模式
```
CH7: HIGH（高位）
          ↓
   PWM1-4恢复（1500）
          ↓
   PWM5-6禁用
```

## 使用方法

### 1. 上传脚本

将 `boat_mode_switch.lua` 上传到飞控SD卡的 `/APM/scripts/` 目录

### 2. 配置参数

| 参数 | 值 | 说明 |
|-----|---|------|
| `SCR_ENABLE` | 1 | 启用脚本功能 |
| `SCR_HEAP` | 1 | 启用脚本堆内存 |
| `SCR_USER2` | 1 | 启用日志写入SD卡（可选） |

### 3. 配置RC通道

将CH7配置为3位开关：
- **低位**（< 1300 PWM）：模式切换触发
- **中位**（1400-1600 PWM）：确认位置
- **高位**（> 1700 PWM）：退出无人船模式

## 通道映射逻辑

### 无人船模式下的PWM控制

| 输入通道 | 输出PWM | 控制功能 | 映射关系 |
|---------|---------|---------|---------|
| CH2（油门摇杆） | PWM6 | 推进电机 | 见下方详细映射 |
| CH3（方向摇杆） | PWM5 | 方向控制 | 见下方详细映射 |

### PWM6映射（CH2 - 油门/前进）

| CH2值 | 百分比 | PWM6输出 | 电机状态 |
|-------|--------|----------|---------|
| 1000 | -100% | 2000 | 正向全速 |
| 1500 | 0% | 1500 | 停止 |
| 2000 | +100% | 1000 | 反向全速 |

### PWM5映射（CH3 - 方向/转向）

| CH3值 | 百分比 | PWM5输出 | 电机状态 |
|-------|--------|----------|---------|
| 1000 | -100% | 1000 | 反向全速 |
| 1500 | 0% | 1500 | 停止 |
| 2000 | +100% | 2000 | 正向全速 |

### 控制逻辑总结

- **CH2（油门）**：1500为中点，小于1500时前进加速，大于1500时后退加速
- **CH3（方向）**：1500为中点，小于1500时反向，大于1500时正向

### 正常飞行模式

| PWM通道 | 状态 |
|---------|------|
| PWM1-4 | 恢复（1500中位） |
| PWM5-6 | 禁用（0） |

## 状态机说明

```
┌─────────────┐
│   NORMAL    │ ← CH7中位开机后
└──────┬──────┘
       │ CH7=LOW + 非飞行状态
       ↓
┌─────────────┐
│   LOW1      │ ← 第一次检测低位
└──────┬──────┘
       │ CH7=MIDDLE
       ↓
┌─────────────┐
│  MIDDLE     │ ← 等待第二次低位
└──────┬──────┘
       │ CH7=LOW
       ↓
┌─────────────┐
│   LOW2      │ ← 确认低位（保持500ms）
└──────┬──────┘
       │ 500ms后
       ↓
┌─────────────┐
│  BOAT_MODE  │ ← 无人船模式
└──────┬──────┘
       │ CH7=HIGH
       ↓
┌─────────────┐
│   NORMAL    │ ← 恢复正常飞行模式
└─────────────┘
```

## 安全机制

### 1. 开机稳定检测
- 开机时必须先检测到CH7中位才能响应切换
- 防止开机时误触发的低位被识别为切换指令

### 2. 非飞行状态限制
- 检测到CH7低位时，必须处于非飞行状态
- 如果飞机正在飞行，拒绝切换并提示

### 3. 双重确认
- 必须经历 LOW → MIDDLE → LOW 的完整流程
- 防止误触导致的意外切换

### 4. 确认延时
- 第二次低位需要保持500ms才能确认
- 进一步防止误触发

## 可调参数

| 参数名 | 默认值 | 说明 |
|-------|-------|------|
| `CH7_PIN` | 7 | RC通道7（模式切换） |
| `CH2_PIN` | 2 | RC通道2（油门/前进） |
| `CH3_PIN` | 3 | RC通道3（方向/转向） |
| `CH_LOW_THRESHOLD` | 1300 | 低位阈值 |
| `CH_HIGH_THRESHOLD` | 1700 | 高位阈值 |
| `CH_MIDDLE_MIN` | 1400 | 中位最小值 |
| `CH_MIDDLE_MAX` | 1600 | 中位最大值 |
| `PRINT_INTERVAL` | 2000 | 通道数据打印间隔(ms) |
| `DEBUG_INTERVAL` | 10000 | 调试信息打印间隔(ms) |

## 故障排除

### 问题：脚本不运行

**解决方案**：
- 检查 `SCR_ENABLE=1` 和 `SCR_HEAP=1`
- 确认脚本路径：`/APM/scripts/boat_mode_switch.lua`
- 查看GCS消息是否有错误提示

### 问题：状态机不响应

**解决方案**：
- 确保开机后先检测到CH7中位
- 检查CH7通道PWM值是否在阈值范围内
- 确认飞行器处于非飞行状态

### 问题：PWM未禁用

**解决方案**：
- 检查地面站Servo Output页面
- 确认PWM1-4输出值是否为0
- 检查电调信号连接

### 问题：日志未写入

**解决方案**：
- 检查SD卡是否正常
- 确认 `SCR_USER2=1`
- 检查日志文件路径
